# Livia.Dev

Portfólio pessoal em desenvolvimento. Esta primeira versão reúne a identidade visual, navegação responsiva, apresentação inicial e estruturas provisórias para as demais seções. Informações profissionais e links de contato serão adicionados quando fornecidos pela Livia.

## Executar localmente

Requisitos: Node.js e npm.

```bash
npm install
npm run dev
```

Abra o endereço local exibido pelo Vite no terminal.

## Verificar a compilação

```bash
npm run build
```

## Organização

- `src/components/`: componentes da interface.
- `src/data/portfolio.ts`: dados provisórios editáveis.
- `src/three/`: protótipo 3D preservado para uma futura etapa.
- `src/*.css`: estilos globais e das seções.
- `public/`: imagens e metadados visuais.
- `docs/design/` e `DESIGN.md`: direção visual e revisão técnica.

Os botões de currículo e redes sociais estão desativados até que os links e o arquivo reais estejam disponíveis.
